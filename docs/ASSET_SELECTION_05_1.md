## License gate and decision

[Fab's official license summary](https://www.fab.com/eula) distinguishes incorporating assets into projects from standalone redistribution. A public source repository exposes source assets: a purchased/free marketplace tier is not evidence of permission to redistribute those source files. Exact selected listing terms remain unverified for the Fab candidates, so no Fab bytes enter this revision.

[Poly Haven's official asset license](https://polyhaven.com/license) states CC0, permits redistribution and does not require attribution. Record authors, exact download URLs, resolution and SHA256 for each selected file. Only selected maps are acquired, not a library. Software/API/site terms remain separate from the asset license.

Decision: original fictional ROOK-5 mesh and hand/animation derivative, limited CC0 PBR surface input, original low-detail industrial/urban silhouette kit. The new gun is a designed loft/subdivision surface with explicit sight axes, not another set of beveled boxes. Preserve Phase03/05 assets. Source budgets: weapon+optic approximately35–70k triangles, practical material families and2K textures; distant architecture uses far fewer triangles and no interiors/collision/navigation. All values are planning estimates until measured.

## Technical research

- [UE5.8 First Person Rendering](https://dev.epicgames.com/documentation/unreal-engine/first-person-rendering): native per-camera first-person FOV/scale on tagged primitives; same-pass rendering. Installed CameraComponent/PrimitiveComponent headers confirm setters. Evaluate conservative first-person scale with the same viewmodel/world FOV first; do not add a scope camera or change renderer configuration. Advanced shadow features have project-setting constraints.
- [Blender IK](https://docs.blender.org/manual/en/4.5/animation/constraints/tracking/ik_solver.html) and [Child Of](https://docs.blender.org/manual/en/4.5/animation/constraints/relationship/child_of.html): installed bpy constraint properties are checked before use. Web manual fetch was unavailable in this session; do not claim online API validation from that failure.
- Native static-mesh sockets are the visual contract: SightAnchor_Iron and SightAnchor_Optic. Solve the root transform so the selected frame points along camera+X at the authored eye relief; keep gameplay hitscan camera-oriented. Recoil/cover pose returns to the same solved transform. Lens reticle belongs to the optic aperture, not a screen-space floating HUD replacement.
