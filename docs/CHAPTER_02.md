# 第二章《回声渡口》 · Echo Crossing

2026-11-18，项目所有者授权制作游戏开场、剧情介绍与回顾，以及第二章的规划和可玩内容。章节地点、设施、记录文字和回波谜题是本次可玩稿的创作提案。已确定的世界设定见[故事设定](STORY.md)。

## 玩家在什么时候知道什么

| 时点 | 玩家知道的事 | 留给玩家的问题 |
| --- | --- | --- |
| 新游戏开场 | 故事发生在 2118 年。数十年前的 The Quieting 让全球基础设施停摆。机械维修技师 Elias Venn 抵达废弃铁路场，工坊里还有灯光。 | 附近的中继站还能不能启动？ |
| 第一章收束 | Elias 从维修工坊取回电力模块，给地下的 Relay Nine 通电。仪表收到一段不规则载波，终端显示 MERIDIAN NETWORK / CONNECTION RESTORED。 | 接通的线路从哪里返回？ |
| 第二章开头 | 线路在洪泛平原的一座旧测站渡河。水面上的电缆、岸上的取样点和远岸天线构成可追踪的路线。 | 仪器收到的是本地回声，还是沿渡口线路返回的载波？ |
| 第二章结束 | 玩家用档案里的参考方位校准天线，检验回波，再把可重复的线路结果送回 Relay Nine。 | 确认线路仍可工作之后，另一端是什么？ |

MERIDIAN 的性质、灾变起因、信号发送者的身份仍是悬念。玩家在第二章取得的证据是一段经过实测的线路回波。

## 开场与回顾

新游戏的开场在确认后播放。片头用动画给出年代、The Quieting 和 Elias 的身份，再把控制权交给刚刚到达铁路场的玩家。第一章结尾原有的终端文字之后可以进入第二章。章节间回顾按工坊回收、地下供电、收到载波的因果顺序交代来路，再落到渡口的任务。读档直接回到游戏。“Chapters & story”可重播两段动画。字幕为英文，片中提供可点击的跳过按钮，也支持 Tab、Enter 和 Esc。

### Blender 过场分镜

两段影片共用同一套 Elias 角色和手部骨架。服装、面部和机柜外观是这版镜头的美术方案。镜头中的模块是工坊取得的电力模块。回波的来源要到渡口由玩家调查。

| 影片时间 | 玩家在画面和声音里获得的信息 |
| --- | --- |
| 开场 0–9 秒 | 2118 年的废弃铁路场。靴底从碎石踏上金属，镜头跟着维修技师 Elias 接近停摆的设备。 |
| 开场 9–18 秒 | 他擦过观察窗、敲了敲外壳。旧设备毫无反应，远处工坊却还有光。接入第一章的铁路场。 |
| 回顾 0–8.5 秒 | Elias 来到地下中继站，一手扶住机柜，另一只手把工坊取回的模块送进插槽。 |
| 回顾 8.5–12.5 秒 | 他合下手柄。金属落锁后机柜通电，表针开始抬升。 |
| 回顾 12.5–21 秒 | 短测试音先响，随后收到断续的回音。观众能看见仪表变化和 Elias 抬眼寻找声音来向。 |
| 回顾 21–24 秒 | 镜头切到河面与远岸天线。自然播完后，游戏把控制权交给渡口岸边的玩家。 |

要调整动作或机位，打开[开场工程](../CinderRelay/ArtSource/Blender/Campaign/CR_Opening3D.blend)或[回顾工程](../CinderRelay/ArtSource/Blender/Campaign/CR_Recap3D.blend)，用时间轴上的相机标记定位镜头。按工程设置以 24 fps 输出从 0001 开始的 JPEG 序列，再运行同目录下的 `finish_films.py`。参数 `opening` 或 `recap` 选择对应的同期声、字幕和成片文件名。

## 关卡制作方案

| 区域 | 玩家行动 | 场景如何回应 |
| --- | --- | --- |
| 河岸取样口 | 沿岸边电缆找到测点，读取 Relay Nine 的回波。 | 取样给出对岸设施的线索，档案厅成为下一目标。 |
| 双栈桥 | 短桥的信号横杆挡路。玩家可以打落醒目标记的卡扣，也可以经敞开的巡检桥绕行。 | 短桥横杆倒下，北侧瞭望点另有一页可收集的观察记录。射击和收集均可跳过。 |
| 档案厅 | 读取参考记录，找到与渡口相符的天线方位。 | 参考条进入任务背包，可在攀登塔架前复核。 |
| 天线平台 | 登上斜坡，操作方向和检验两个控件。故意在错误方位检验会得到本地回波提示。 | 天线随调节转动，正确检验后发送台才可用。 |
| 发送台 | 把验证结果送回 Relay Nine。 | 完成两章之间提出的问题，显示本章结算。 |

独立的第二章检查点记录稳定步骤和已取得的线索。恢复时重建天线和桥闸状态。主菜单支持直接选第二章，第一章结尾的正常转场则带入当时的装备状态。两章使用各自的存档槽。

渡口和塔台用了八件原创 Blender 模型。北桥外的测绘艇长 8.61 米，船舱、桅杆和绞盘能从岸上辨认。可旋转的天线与操作台共用正确的方位，图板上的标记对应可操作的 120° 刻度。[可编辑 Blender 模型库](../CinderRelay/ArtSource/Blender/Chapter02/CR02_EchoCrossing.blend)

## 验收路线

1. 从 New Game 自然播放开场，检查画面、字幕、音效和第一章控制权。通过章节菜单重播或跳过一次。
2. 从第一章结束画面进入渡口，检查回顾和携带装备。另从主菜单验证独立选章入口。
3. 在渡口取样，经过栈桥和档案厅，退出进程。重新启动后读取第二章检查点，先测试错误方位，再调准发送，核对结算和存档回调。
4. 真人短测从档案厅走到发送台，观察是否能够凭参考条理解“调方向”和“做检验”的区别。
